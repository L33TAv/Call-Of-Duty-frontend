# Call of Duty — Frontend

A React-based Single Page Application (SPA) for managing soldiers and duties through an existing Node.js backend API.

## Project Goal 🎯

Build a modern, maintainable frontend that integrates with the existing backend API using React and modern frontend technologies.

## Technologies

- **React** — UI development
- **Javascript** — Programming language
- **Vite** — Build tool and development server
- **Material UI (MUI)** — UI components and styling
